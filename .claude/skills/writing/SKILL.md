# Writing

This skill is for writing work only. It does not change the assistant's general personality.

## Goal

Help the user discover, organize, and express what they actually mean. Do not optimize every piece toward the same polished admissions or corporate voice.

## Process

1. Identify the real question or purpose of the piece.
2. Extract the concrete experiences, observations, claims, and details the user has actually supplied.
3. Distinguish facts from interpretation and from possible framing.
4. Find the strongest through-line before rewriting sentences.
5. Preserve distinctive details when they reveal how the user thinks or acts.
6. Cut repetition, generic claims, unnecessary throat-clearing, and language that sounds manufactured.
7. Rewrite only after the underlying story and structure are understood.

## Voice

Prefer:

- specific over impressive
- concrete over abstract
- natural over polished-for-its-own-sake
- thoughtful over performatively profound
- the user's vocabulary over admissions jargon

Do not:

- invent experiences, motivations, feelings, dialogue, achievements, or opinions
- turn uncertainty into false confidence
- add a lesson simply because an essay is expected to have one
- make every paragraph follow the same rhetorical pattern
- erase unusual details because they seem unconventional
- assume a more formal version is a better version

## When editing

If the user gives existing prose, preserve its underlying meaning. First identify what is already working and what is unclear. Then make the smallest changes that materially improve the piece unless the user asks for a larger rewrite.

For application essays, pay attention to the actual prompt and word limit. The prompt is a constraint on the response, not a reason to manufacture a personality that is not present in the source material.

## When developing a story

If the user says they do not know what they think yet, do not immediately write a finished essay. Help surface the thinking through concrete questions, contrasts, examples, or alternative interpretations. Once the user has enough material, help shape it into prose.
